# Design system

Source of truth: the Jakob Alex design system (kept privately). The live implementation is the site: https://github.com/jakob-alexander2000/site (see DESIGN.md there).

Monochrome (#f2f2f0 ground, #0b0b0b ink, white sheets), red only for a failed check. Archivo (wordmark 800 at width 125, headlines 700), Martian Mono for data. Two rules: 3 px heavy, 1 px hair. Square corners. Fig. 1, the exploded section, is the motif.
