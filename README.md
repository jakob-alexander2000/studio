# Studio

How I work, as files. Every project goes through four layers, and each one leaves something the next one uses.

| Layer | Leaves behind | Folder |
| --- | --- | --- |
| Research | a brief | `research/` |
| Design | a spec sheet | `design/` |
| Code | a repo | `code/` |
| Checks | a receipt | `checks/` |

What fails a check goes back into research as next week's question. The public site shows the same four layers.

Agents read `AGENTS.md` and the skills in `.claude/skills/`. Thinking happens in Notion; finished output lands here.
