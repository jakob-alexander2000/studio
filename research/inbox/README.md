# Inbox

Raw input for the Sunday radar from other tools. Right now that's Jakob's weekly tech radar from Grok.

## How to add one

1. Ask Grok for its tech radar for the week.
2. Make a new file here named `YYYY-Www-grok.md`, for example `2026-W48-grok.md`, and paste the answer in as it is. On a phone, the GitHub app or github.com both work.
3. Commit straight to `main`. The Sunday radar picks it up that evening.

This repo is public. Paste only the radar itself: no personal notes, names or private links.

## How the radar treats it

An inbox file is a lead, never a source. The radar opens every claim at its original link. If it can't find one, the item is dropped, or listed once under "Unconfirmed" if it matters to a project. Grok's opinions don't decide where an item lands in Adopt, Trial, Assess or Hold.

Files stay here after use, so it stays visible which leads made it into a radar.
